## 3. Campanhas no Meta: recusado

O endpoint respondeu HTTP 502, código `BADGATEWAY`, com esta mensagem
exata:

> Leitura de campanha desligada: falta META_ADS_ACCESS_TOKEN (com
> ads_read) ou META_AD_ACCOUNT_ID.

Então não há número de campanha, gasto, clique nem custo por resultado
neste relatório. Para destravar, o fundador precisa pôr no serviço da
API no Render duas variáveis: `META_ADS_ACCESS_TOKEN` (token de Usuário
do Sistema com `ads_read`) e `META_AD_ACCOUNT_ID`. O caminho está no
fim de `empresa/marketing/COMO-LIGAR-O-PIXEL.md`.
